# Frontend

Dashboard en React + Vite para consumir la API local del proyecto.

## Ejecutar

```bash
cd frontend
npm install
npm run dev
```

## URL esperada

- Frontend: `http://localhost:5173`
- Backend: `http://localhost:8000`

## Componentes

- `PredictionForm`
- `PredictionResult`
- `AlertsTable`
- `MetricsPanel`
- `ArchitecturePanel`
